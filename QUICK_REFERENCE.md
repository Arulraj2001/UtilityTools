# Quick Reference - SEO Content Feature

## 🎯 Quick Start (5 minutes)

### To Add seo_content to a Tool:

1. **Go to Admin Panel** → Find tool → Click Edit
2. **Click "SEO Content" tab** (between SEO and FAQ)
3. **Paste or write HTML content**
4. **Click Save** → Changes live immediately

### Minimal HTML Example:
```html
<h2>How to Use This Tool</h2>
<p>Enter your information and click calculate.</p>

<h2>Best Practices</h2>
<ul>
<li>Double-check your input</li>
<li>Review the output carefully</li>
</ul>
```

---

## 📋 HTML Cheat Sheet

| What | Code | Result |
|------|------|--------|
| Main heading | `<h2>Title</h2>` | Large bold text |
| Sub-heading | `<h3>Subtitle</h3>` | Slightly smaller |
| Paragraph | `<p>Text here</p>` | Normal text |
| List | `<ul><li>Item</li></ul>` | Bullet points |
| Numbered | `<ol><li>Step</li></ol>` | Numbered steps |
| Bold | `<strong>important</strong>` | **important** |
| Italic | `<em>emphasis</em>` | *emphasis* |

---

## 📊 Word Count Target

- **Minimum:** 300 words (better than nothing)
- **Good:** 500-800 words (solid SEO value)
- **Excellent:** 1000-1500 words (strong ranking potential)
- **Too Long:** 2000+ words (may hurt page speed)

## ✅ SEO Content Checklist

Before clicking Save:

- [ ] Contains 500+ words (target)
- [ ] Uses h2 and h3 headings
- [ ] Includes 3-5 primary keywords naturally
- [ ] Has at least 2 lists with bullet points
- [ ] Includes real-world examples
- [ ] Uses proper HTML formatting
- [ ] No broken HTML tags
- [ ] HTML preview looks good
- [ ] Mentions related tools if relevant
- [ ] Content is original (not copied)

---

## ⚠️ Common Mistakes to Avoid

### ❌ Don't:
- Copy-paste from Wikipedia or other sites
- Stuff keywords unnaturally
- Use h1 tags (page title is h1)
- Write meta descriptions (use SEO tab for that)
- Include external links without reason
- Use images without captions
- Make content too technical
- Duplicate FAQ answers exactly

### ✅ Do:
- Write original, unique content
- Integrate keywords naturally
- Use h2 for main sections
- Focus on user value
- Link to your own related tools
- Explain concepts clearly
- Match user intent
- Expand on FAQ content with examples

## 🛠️ Troubleshooting

### Content not showing?
1. Make sure tool is "published" (not draft)
2. Check if field is empty
3. Verify HTML syntax (no broken tags)

### Looks weird/broken?
1. Check for unclosed tags
2. Use valid HTML only
3. Keep structure simple

### Too long/slow?
1. Reduce content to 1500 words max
2. Remove any images if embedded
3. Simplify HTML structure
